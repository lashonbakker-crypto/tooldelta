What “verified” means — and what it does not

ToolDelta validates a bounded subset: types, object properties, required fields, additional properties, enums, const, numeric bounds, string length, array items/length/uniqueness, and property counts. Unknown keywords, references, patterns, composition and custom dialects disable verified examples for that tool. Candidate search is bounded and may find no example even when one exists. A request may demonstrate multiple findings. Output schemas, descriptions and advisory permission hints require review. This is neither a full compatibility proof nor a security verdict. Inputs are limited to 2 MiB each, 200 tools, bounded nesting and analysis work; browser jobs stop after five seconds. Snapshots stay in memory; refreshing clears them. The hosted page still downloads its own code from GitHub Pages.
